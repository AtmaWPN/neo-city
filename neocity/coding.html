8Vim Demo for Gamepad and Mouse

I made this because I got a little obsessed with 8Vim.

If you have a gamepad connected, make any input to start using it, not all gamepads are supported.

The right joystick moves between sectors and the right trigger presses and un-presses.

If you don't have a compatible gamepad you can use your mouse.


Cipher

This is a neat little cipher that I made for encrypting HTML content.

I based it on an old cipher that I read about and modified to skip HTML tags and use the full range of printable ASCII characters.

I use this cipher for information that I want to be difficult but possible to access.
